# KnowledgeHub

Стартовый MVP на Next.js. Запуск: `npm install && npm run dev`.

Первый канал: https://youtube.com/@olegcloser

Пока доступны только интерфейс и временный список ссылок. Следующие этапы: Supabase, авторизация, YouTube Data API, обработка разрешённых текстов и ИИ-поиск. Видео не скачиваются. Секреты не публиковать в GitHub.
